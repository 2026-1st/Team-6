# 노트북 폴더 안내

노트북은 숫자 순서대로 실행하는 것을 권장한다.

```text
00_full_pipeline/
01_eda_sampling/
02_feature_engineering/
03_text_embedding/
04_modeling_analysis/
```

재사용 가능한 데이터는 `data/`에 저장하고, 그래프/표/보고서 산출물은 `output/`에 저장한다.

`00_full_pipeline/Team6_Full_Pipeline.ipynb`는 전체 과정을 한 파일로 합친 검토용 노트북이다. 실제 수정이나 단계별 재실행은 번호가 붙은 개별 노트북을 기준으로 진행하는 것이 더 안전한다.
